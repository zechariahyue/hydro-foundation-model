     must be re-tested on a ceiling-free skill score (below).

(2)+(3) CEILING-FREE RE-TEST + NULL CONTROL
==============================================================================
PSS = 1 - (1-NSE_model)/(1-NSE_pers) = fraction of persistence's squared error
      that the model removes.  PSS>0 = genuine information beyond lag-1.
      PatchTST is the NULL CONTROL: it has ~zero skill, so if it also shows a
      rising trend toward flashy basins, the trend is an artefact.

  * If PSS_tfm is ~flat across bins -> the dNSE trend was a CEILING ARTEFACT.
  * If PSS_tfm rises toward flashy basins AND PSS_patchtst does not
    -> TimesFM genuinely extracts information beyond lag-1 in flashy basins.
  * If PSS_patchtst ALSO rises -> regression to the mean. Finding is dead.
