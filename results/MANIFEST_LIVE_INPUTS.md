# Live inputs backing the manuscript — protocol tag `l5s7`

Last verified: **2026-09-06**. Target journal: ERL (IOP).

This directory mixes current and superseded outputs. Nothing in the filenames distinguishes
them, which is a standing contamination risk. **This file is the authority on which artifacts
back the submitted manuscript.** If a file is not listed under "LIVE" below, do not cite it, do
not read it into an analysis, and do not reconcile a manuscript number against it.

## The one protocol

Every number in the main text comes from a single protocol: the **most recent five years of each
basin's record, uniform stride 7, with all models scored on identical one-day-ahead target
points**. Files carrying that protocol use the suffix **`_l5s7`**. The few-shot arm uses the same
five-year window with suffix **`_l5y`**.

Protocol fairness is independently checkable: because all models share target points, the
observed standard deviation recovered per basin as `RMSE/sqrt(1-NSE)` must agree across models.
It does, to a median relative spread of `2e-16` (see `TAIL_RMSE_NORMALISED_REPORT.txt`).

## Rule for generated tables

`table_hydro_controls.tex` and `table_rainfall_ceiling.tex` are produced by
`experiments/analysis/figure_hydrological_controls.py` and `figure_rainfall_ceiling.py` and then
copied into the manuscript directory, as is `table_ar_baseline.tex` from `ar_baseline_analysis.py`. **Edit the generator, never the manuscript copy.** The `TFM>AR(2)` column of the main-text controls table is typed by hand from `ar_baseline_quartiles.csv` because `figure_hydrological_controls.py` does not read the AR files; re-check it against that CSV after any AR re-run. A
2026-08-06 review caught the two copies disagreeing after a manual edit; regenerate and copy so
they stay byte-identical.
